# Atannex Generator

Creates unique, readable codes for a Laravel app, such as order references, invoice numbers, staff IDs, voucher codes and tokens. You describe the code once as a short pattern (for example a prefix, the year and a running number) and the package fills in a new, unique code every time a record is created.

## Install

```bash
composer require atannex/generator
```
